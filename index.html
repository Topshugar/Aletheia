Definition

Aletheia (ἀλήθεια) — noun. Truth; disclosure; the state of not being hidden.

Aletheia does not track callers. It verifies provenance — whether a call truly originates from the organisation it claims to represent — using only data you provide.

Verify a Call

All processing occurs in your browser. No data is uploaded or stored.

Verdict

Provenance Confidence —

    This report is for evidence preservation. It is not a legal determination of fraud. Report suspected fraud to Action Fraud.

    Methodology

    1. Normalisation: The number is stripped of spaces and converted to international format.
    2. Format Validation: UK numbers are checked against Ofcom numbering rules.
    3. Provenance Comparison: The number is compared to the verified official number for the claimed organisation.
    4. Risk Assessment: A confidence score is derived from the above, not from location tracking.

    Topshugar · Provenance & Truth

    Aletheia is a defensive tool. It does not intercept, track, or locate callers.
